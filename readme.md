Tools, data and reading for choosing a name, checking whether it is free, learning where it has been and managing it.

## Name ideas and generators

- [Domainr](https://domainr.com/) - Domain search that suggests alternatives and domain hacks, with an API.
- [Instant Domain Search](https://instantdomainsearch.com/) - Checks availability as you type.
- [Lean Domain Search](https://leandomainsearch.com/) - Keyword search that shows only names that are free.
- [NameDaemon Domain Name Generator](https://namedaemon.com/tools/domain-name-generator/) - Scored two-word .com ideas checked against a snapshot of the zone. Made by the maintainer.
- [Namelix](https://namelix.com/) - Generates short brandable business names.
- [Panabee](https://www.panabee.com/) - Name ideas with domain and social handle availability.

## Availability and WHOIS or RDAP lookups

- [DomainTools Whois Lookup](https://whois.domaintools.com/) - Registration lookup with history from a commercial provider.
- [IANA WHOIS](https://www.iana.org/whois) - Registry information for top-level domains.
- [ICANN Lookup](https://lookup.icann.org/) - Official registration data lookup using RDAP.
- [RDAP.org](https://about.rdap.org/) - Redirect service that sends RDAP queries to the right registry.
- [ViewDNS.info](https://viewdns.info/) - A set of DNS and domain lookups in one site.
- [who.is](https://who.is/) - Registration lookup with DNS records.

## Expiring and dropped domains

- [DropCatch](https://www.dropcatch.com/) - Backorders for names about to drop.
- [Dynadot Backorder](https://www.dynadot.com/market/backorder) - Backorders at a registrar.
- [ExpiredDomains.net](https://www.expireddomains.net/) - Searchable lists of expiring and deleted domains.
- [GoDaddy Auctions](https://auctions.godaddy.com/) - Auctions of expiring and listed domains.
- [NameDaemon Drop Calendar](https://namedaemon.com/tools/drop-calendar/) - Estimated drop dates for .com names in pending delete. Made by the maintainer.
- [NameJet](https://www.namejet.com/) - Auctions and backorders for expiring names.
- [SnapNames](https://www.snapnames.com/) - Backorder service for dropping names.

## History and reputation

- [crt.sh](https://crt.sh/) - Search of Certificate Transparency logs.
- [Google Safe Browsing Site Status](https://transparencyreport.google.com/safe-browsing/search) - Checks whether a site is flagged as unsafe.
- [Internet Archive Wayback Machine](https://web.archive.org/) - Archived copies of web pages over time.
- [SecurityTrails](https://securitytrails.com/) - DNS history and domain data, with a free tier.
- [Spamhaus](https://www.spamhaus.org/) - Domain and IP blocklists and reputation checks.
- [URLhaus](https://urlhaus.abuse.ch/) - Database of malware distribution URLs.
- [VirusTotal](https://www.virustotal.com/) - Scans a domain or URL with many security engines.

## Trademarks and disputes

- [ICANN UDRP](https://www.icann.org/resources/pages/help/dndr/udrp-en) - The policy for cybersquatting disputes.
- [TMview](https://www.tmdn.org/tmview/) - Search of trademarks from European and other offices.
- [USPTO Trademark Search](https://tmsearch.uspto.gov/) - Search of US trademark registrations and applications.
- [WIPO Domain Name Dispute Resolution](https://www.wipo.int/amc/en/domains/) - Procedure and case database for domain name disputes.
- [WIPO Global Brand Database](https://branddb.wipo.int/) - Search of trademarks from many countries.

## Appraisal and aftermarket

- [Afternic](https://www.afternic.com/) - Marketplace connected to many registrars.
- [NameBio](https://namebio.com/) - Database of historical domain sales.
- [Sedo](https://sedo.com/) - Marketplace for buying and selling domains.

## Registrars and price comparison

- [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/) - Registrar that charges the registry price without a markup.
- [Dynadot](https://www.dynadot.com/) - Registrar with an API and a marketplace.
- [Gandi](https://www.gandi.net/) - Registrar with a long history and an API.
- [ICANN Accredited Registrars](https://www.icann.org/en/contracted-parties/accredited-registrars/list-of-accredited-registrars) - The official list of accredited registrars.
- [Namecheap](https://www.namecheap.com/) - Registrar with low first-year prices.
- [Porkbun](https://porkbun.com/) - Registrar with public pricing and an API.
- [TLD-List](https://tld-list.com/) - Compares registration and renewal prices across registrars.

## DNS and email health

- [awesome-dns by CENTR](https://github.com/CENTRprojects/awesome-dns) - A curated list of DNS tools.
- [awesome-dns by okhosting](https://github.com/okhosting/awesome-dns) - A list of open source DNS tools and free services.
- [DNSChecker](https://dnschecker.org/) - Checks DNS propagation from many locations.
- [DNSViz](https://dnsviz.net/) - Visualises DNSSEC chains and finds errors.
- [MXToolbox](https://mxtoolbox.com/) - Mail server, DNS and blocklist checks.
- [Zonemaster](https://zonemaster.net/) - Checks how well a domain's DNS is set up.

## Lookalikes and typosquatting

- [dnstwist](https://github.com/elceef/dnstwist) - Finds lookalike domains that could be used for phishing.
- [NameDaemon Lookalike Finder](https://namedaemon.com/tools/lookalike-finder/) - Lists registered lookalikes of a brand and who hosts them. Made by the maintainer.
- [URLCrazy](https://github.com/urbanadventurer/urlcrazy) - Generates typo variants of a domain and checks them.

## Libraries and APIs

- [dnspython](https://github.com/rthalley/dnspython) - DNS toolkit for Python.
- [namedaemon (npm)](https://github.com/krasenslavov/namedaemon-npm) - Client and command line for availability, brand scores and TLD costs. Made by the maintainer.
- [namedaemon (PyPI)](https://github.com/krasenslavov/namedaemon-pypi) - Python client and command line for availability, brand scores and TLD costs. Made by the maintainer.
- [rdap](https://github.com/openrdap/rdap) - Command line tool and Go client for RDAP.
- [tldextract](https://github.com/john-kurkowski/tldextract) - Splits a URL into subdomain, domain and suffix using the Public Suffix List.
- [tldts](https://github.com/remusao/tldts) - Fast hostname and domain parsing for JavaScript.
- [whodap](https://github.com/pogzyb/whodap) - RDAP client for Python.
- [whois](https://github.com/richardpenman/whois) - Python library that parses WHOIS records.
- [whoiser](https://github.com/LayeredStudio/whoiser) - WHOIS and RDAP client for Node.js.

## Data and standards

- [IANA Root Zone Database](https://www.iana.org/domains/root/db) - Every top-level domain with its type and sponsor.
- [ICANN Centralized Zone Data Service](https://czds.icann.org/) - Where approved users request zone files.
- [NameDaemon State of .com](https://namedaemon.com/state-of-com/) - Daily numbers on registered .com names from the zone file. Made by the maintainer.
- [Public Suffix List](https://publicsuffix.org/) - List of public suffixes used to find a registrable domain.
- [RFC 1034](https://www.rfc-editor.org/rfc/rfc1034) - Domain names: concepts and facilities.
- [RFC 9083](https://www.rfc-editor.org/rfc/rfc9083) - JSON responses of RDAP.
- [Tranco](https://tranco-list.eu/) - Research-grade ranking of popular domains.
- [Verisign Domain Name Industry Brief](https://www.verisign.com/en_US/domain-names/dnib/index.xhtml) - Quarterly report on domain registrations.

## Learning

- [ICANN EPP Status Codes](https://www.icann.org/resources/pages/epp-status-codes-2014-06-16-en) - What each registry status means.
- [ICANN Expired Registration Recovery Policy](https://www.icann.org/resources/pages/errp-2013-02-28-en) - What registrars must do when a domain expires.
- [ICANN Learn](https://learn.icann.org/) - Free courses on how the domain name system and ICANN work.
- [Verisign .com](https://www.verisign.com/en_US/domain-names/dot-com/index.xhtml) - The registry operator's page about .com.
