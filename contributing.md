# Contribution guidelines

Thank you for helping. This list is a short, curated set of tools and resources for finding, checking and researching domain names. Read this page before you open a pull request.

## What belongs here

An entry must be:

- **Useful for domain names:** finding a name, checking it, researching its history, buying, managing or understanding it.
- **Something you have used or can recommend.** Say in the pull request why it is good.
- **Active:** a website that works, or a repository with a commit in the last 12 months. A mature tool that still works and is widely used can be an exception, if the pull request says so.
- **Free to use, or clearly useful with a free tier.** Paid tools are fine when the free part is real.
- **Neutral:** no pay-to-play, no thin affiliate pages, no lists of names for sale.

Out of scope: DNS server software and DNS operations (see [awesome-dns by CENTR](https://github.com/CENTRprojects/awesome-dns) and [awesome-dns by okhosting](https://github.com/okhosting/awesome-dns)), web hosting, website builders, and blockchain naming services.

## Adding an entry

- One pull request per entry, titled `Add Name`.
- Add the entry at the bottom of the right section, in the format `- [Name](https://example.com/) - Description.`
- The description starts with a capital letter, ends with a full stop and says what the thing is, not how great it is. No marketing wording.
- Link to the project's own page or repository, not a review or affiliate link.
- Check your spelling and remove trailing spaces.
- If you are the maker, say so in the pull request. Makers are welcome, but one entry each.

## Other changes

Fixing a dead link, a typo or a description is always welcome, as are suggestions for a new section (open an issue first).

## Review

A maintainer reads each pull request. Entries that do not meet the rules above are closed with a short reason. The list is checked for dead links every month, and entries that no longer work or are no longer maintained are removed.
